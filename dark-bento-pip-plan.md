# Dark Bento portfolio and Pip

Build one iOS-inspired web portfolio that feels consistent on Windows Chrome, Safari, and mobile. Keep Akihito’s identity rail and mixed-size tiles, make the work the focus, and offer an optional four-stop tour led by a 2D Rive companion.

## Build order

1. **Use Ink Guide for Pip.** The [selected Ink Guide design](public/images/pip/ink-guide.svg) has a cream paper face, dark ink lines, cobalt hands and shoes, and a hand-drawn orbit. Preserve the folded corner and readable face at launcher size. Rig the eyes, gesture, orbit, and celebration marks independently.
2. **Set the visual rules.** Use the approved dark Bento layout and palette. Set shared tokens in `src/styles.css` for charcoal canvas, quiet borders, 16–24 px corners, blue focus, Manrope headings, and Source Sans 3 text. Default to dark on first visit and remember a visitor’s light mode choice. Use an opaque fallback for glass and adapt layout to viewport size. [Akihito’s Bento](https://refero.design/pages/8c2946d6-93be-4d6d-aaa1-8fb332c5c2ba) · [Apple materials](https://developer.apple.com/design/human-interface-guidelines/materials)
3. **Build the homepage.** Use a responsive grid in `src/routes/index.tsx` for Orbit, full-image Stack, GitHub and About tiles, then the rest of Selected Work. Put the identity above the grid on small screens. Keep case-study URLs, content, and contact actions accessible through real links. Reuse the existing command menu and theme controls. Aceternity’s grid, Konsta’s iOS theme, and Base UI’s Drawer are references for future component work. [Aceternity grid](https://ui.aceternity.com/components/bento-grid) · [Konsta provider](https://konstaui.com/react/konsta-provider) · [Base UI Drawer](https://base-ui.com/react/components/drawer)
4. **Produce the static artwork.** Give Stack, GitHub, and About their own illustrated widgets. Apply one 2D art direction across the eight project covers, with a subject tied to each actual project. Use the approved mockup’s blue and lilac palette, and build depth with layered shapes and gradients. Use compressed WebP, preserve explicit image dimensions and useful alt text, and keep concept art labeled in `ProjectVisual`.
5. **Author and export Pip.** The selected Ink Guide is authored in [Rive Markup Language](design/pip/scene.rml). The script-free artboard uses the Guide View Model’s `pose` property to select Idle, Hello, Point, Inspect, Nod, and Celebrate. Rive CLI 1.9.2 verified the source and rendered all six states. The [local export](public/images/pip/pip-guide.riv) carries the workspace’s Rive splash screen. Use the [still portrait](public/images/pip/ink-guide.svg) for reduced motion and as a loading or error fallback. [Rive CLI](https://rive.app/docs/cli/overview) · [Rive Data Binding](https://rive.app/docs/runtimes/react/data-binding)
6. **Connect the walkthrough.** Offer a dismissible first-homepage invite, then cover Orbit → Selected Work → About, Stack and Résumé → Contact. On internal pages, let visitors meet Pip and start the tour from Orbit. React owns progress, anchors, focus, links, Back, Next, Skip, Escape, Done, and Replay. Persist skip or completion under a versioned local key. Keep the guide usable if a target is missing. Start `@rive-app/react-canvas` after opt-in, keep the text usable with the still portrait, and stop playback when the tour closes. [Duolingo character animation](https://blog.duolingo.com/world-character-visemes/) · [Rive React](https://rive.app/docs/runtimes/react/react)
7. **Verify the result.** Run the production build, TypeScript, and targeted lint. In Windows Chrome, iOS Safari, and Firefox, check the desktop and narrow layouts, keyboard and touch navigation, focus return, direct case-study links, theme contrast, and reduced motion. Exercise tour completion, dismissal, replay, missing art, and disabled WebGL. Compare the rendered home to the approved mockup and confirm initial page load makes no Rive runtime or art request.

## Pip’s motion

Use a short performance for each tour cue. Pip breathes at rest, crouches before waving hello, looks toward Orbit before pointing, leans in with a curious expression to inspect the work, nods twice at About, and jumps into a burst of ink rays at completion. The paper corner, orbit, and gloves settle after the body lands. Rive plays the first greeting into Point and lets visitors advance immediately while a gesture plays. Blinking has its own state machine layer, so it continues while a gesture holds.

### References applied to the rig

- Duocon’s animation team explains how gaze directs attention and how concurrent animation systems preserve expression during reactions. Pip’s gaze gets to Orbit ahead of the pointing glove, and its resting blinks run alongside the tour gestures. [Duocon on gaze](https://www.youtube.com/watch?v=fgOqvyPif3g&t=114s) · [Duocon on layered animation](https://www.youtube.com/watch?v=fgOqvyPif3g&t=311s)
- Pedro Alpera’s Octopus Loop, aln.omrv’s character rig, and the Rive character tutorial separate idle motion from blinking. Pip’s resting blink scales the parent of its eyes, while the gesture tracks shape each eye for a particular reaction. The loop spaces blinks unevenly, with a brief double blink. [Octopus Loop](https://rive.app/community/files/4974-10065-octopus-loop/) · [Interactive Character Rig](https://rive.app/marketplace/28370-53642-interactive-character-rig-bones-joysticks-and-data-binding/) · [Build Interactive Characters in Rive](https://www.youtube.com/watch?v=-vuQvvFiR8s&t=362s)
- Alan Becker’s examples connect anticipation, volume, and follow-through. Rive’s bounce tutorial distinguishes an accelerating fall from a quick squash on impact. Pip now crouches before launch, slows near the top, accelerates into the landing, and lets the folded corner and orbit catch up. [Becker on squash and stretch](https://www.youtube.com/watch?v=uDqjIdI4bF4&t=10s) · [Becker on follow-through](https://www.youtube.com/watch?v=uDqjIdI4bF4&t=554s) · [Rive on the landing curve](https://www.youtube.com/watch?v=DitdOy_HxKc&t=298s)
- With Love Lab’s GoodGood study ties blinks to an intended gaze shift and mixes those cues with occasional resting blinks. Pip blinks as it redirects its gaze and squints briefly on landing. [GoodGood’s eye system](https://withloveapp.substack.com/p/procedural-animation-in-rive-how)

## Release verification

The production build, TypeScript, scoped ESLint, and accordion SSR check passed. Windows Chrome covered all 14 content routes, the internal-page greeting, the transition to the homepage tour, keyboard focus, tour completion and replay, and touch input at 320 px. Pip loaded after opt-in and animated with WebGL disabled. Firefox and Playwright WebKit passed greeting animation and reduced-motion checks. Earlier checks covered the missing-scene and missing-anchor fallbacks. Physical iOS Safari remains untested.
