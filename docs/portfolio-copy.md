## About

I care about what happens after the demo.

I'm Huzaifa Shahid. AI product builder. Curious about the details.

A useful product has to hold up when the input is messy or a task goes wrong. That's where I spend my time: the workflow and the next step the interface gives you.

My work includes Orbit, an AI workspace with memory and tool permissions, and Errby, a learning partner that asks you to explain what you know. I'm also exploring haircut planning with TAYPR and practical agent tooling with SkillTube.

I like small, clear interfaces. But the work behind them can be complicated, especially keeping private data private and knowing when the user needs to step in.

These projects are at different stages. Each page makes its current stage clear so you can see what's there today.
